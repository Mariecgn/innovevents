# Documentation utilisateur

## Visiteur
- Consulter l'accueil.
- Consulter les événements publics.
- Envoyer une demande de devis.
- Contacter la société.

## Client
- Se connecter.
- Consulter ses devis.
- Accepter, refuser ou demander une modification.
- Modifier ses informations personnelles.
- Déposer un avis après événement.

## Employé
- Consulter les clients et événements.
- Ajouter des notes collaboratives.
- Modifier ses tâches assignées.
- Valider ou refuser les avis.

## Administrateur
- Gérer les prospects.
- Convertir un prospect en client.
- Gérer clients, événements, devis et utilisateurs.
- Générer et envoyer un devis PDF.
- Consulter les logs.
